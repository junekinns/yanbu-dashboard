# Red Sea Watch · 사우디

US Pizza Index처럼, 공식 발표가 말하지 않는 것을 간접 신호로 읽는 비공식 대시보드. 사우디아라비아에 있는 한인 교민(주로 아람코 근무 가족)용. **서부(얀부·제다) / 중부(리야드) / 동부(담맘·다란·주베일)** 세 권역을 탭 전환 없이 한 페이지에서 동시에 보여준다.

**https://junekinns.github.io/yanbu-dashboard/**

## 세 가지 지표 (권역별, 3단계 배지로 단순화)

숫자·배율 대신 위험/주의/평시(또는 정상/감소/끊김) 3단계 배지 하나로 보여준다. 상세 수치는 배지 아래 한 줄과 미니 그래프에.

| 지표 | 데이터 | 배지 |
|---|---|---|
| 위성 열 감지 | NASA FIRMS VIIRS(S-NPP) 7일 화점 CSV, 권역 bbox. 7일 중 4일 이상 같은 3km 격자에 잡히는 상시 열원(정유 플레어)은 제외 | 24시간 이상 화점 수 ÷ 평시(이력 중앙값) — 위험 / 주의 / 평시 |
| 공지 템포 | 외교부 해외안전여행 사우디 안전공지 (`ntnCd=107`), 전국 | 최근 7일 건수 ÷ 평시 중앙값 — 급증 / 증가 / 평시. 이미 벌어진 일에 대한 정부 대응이라 선행성은 약함(참고용) |
| 해상 교통 | IMF PortWatch (AIS 집계, ArcGIS FeatureServer) — 서부 얀부 King Fahd 항, 동부 주아이마(아람코 원유 터미널), 중부는 호르무즈 해협 | 최근 7일 ÷ 지난 1년 중앙값 — 끊김 / 감소 / 정상. **낮을수록 위험** |

(이전에는 위키피디아 조회수로 "관심도"도 표시했으나, 애초에 사우디 정세가 이미 주목받고 있어서 만든 대시보드에 "주목도"를 지표로 쓰는 건 순환논리라 제거했다. "아람코 주가·타다울 지수"도 시도했으나 아래 참고.)

## 그 외

- **외교부 경보 한 줄**: 권역 내 3단계(출국권고) 지명과 나머지 단계.
- **공격·요격·경보 로그**: 사우디에는 공개 사이렌 API가 없다. 민방위 경보·연합군 요격 발표가 1~2시간 안에 주요 매체에 보도되는 점을 이용해 영문·국문 Google News 결과를 허용 매체로 걸러 (현지 날짜·대상 도시·유형[경보/요격/피격/공습])로 묶는다. 부인·분석·후속 경제기사는 제외. 선택 권역은 붉은 줄, 6시간 이내 사건은 지도에서 깜빡임으로 강조.
- **후티 군 대변인 채널**: Telegram @army21ye(예멘군 대변인 야히야 사리 공식 채널)의 웹 미리보기를 읽어 사우디 지명(아랍어)을 언급한 메시지만 표시. MyMemory 무료 번역 API로 한국어를 우선 표시하고, 아랍어 원문은 접어서 제공(자동 번역, 오역 가능). 상대측 발표라 검증되지 않음을 명시.
- **권역 지도**: 선택 권역만, 요소 세 가지 — 도시(외교부 단계 색, 클릭하면 항만 활동), 사건(유형별 색, 매체 수 크기, 6시간 이내는 깜빡임, 클릭하면 기사), 위성 이상 화점. 24시간/72시간/7일 범위 토글 + 지도/위성(Esri World Imagery) 바탕지도 토글.
- **외교부 최근 공지 3건**(본문 첫 줄 요약), **언론 보도** 국내·해외 5건씩(주요 매체 허용목록, 매체당 2건).
- **수동 갱신**: 정적 사이트라 버튼 클릭으로 서버 재계산은 못 시킨다. 대신 ①"새로고침" 버튼 — 캐시 무시하고 `data/latest.json`을 다시 받아 이미 갱신된 최신값이 있으면 반영, ②"지금 바로 데이터 재수집" 링크 — GitHub 로그인 후 Actions에서 workflow_dispatch를 수동 실행. 자동 수집 주기 자체도 6시간→**매시간**으로 단축(공개 저장소라 Actions 사용량 무료).

## 지도 고도화: 조사 결과

Palantir AIP급 실시간 미사일 궤적·3D를 문의받아 조사함.

- **실시간 미사일 궤적/아이콘**: 불가능. 요격·발사 데이터는 각국 군 레이더 텔레메트리 영역이라 무료 공개 API가 없음(이스라엘의 Home Front Command 사이렌 API 같은 게 사우디엔 없음). 지금 지도에 찍는 사건 마커는 "보도된 사건의 대략적 위치"이지 실제 탄도 좌표가 아님 — 이 한계를 명확히 유지.
- **위성뷰**: 채택. Esri World Imagery는 무료·무키 타일이라 바탕지도 토글로 추가. 실제 위성사진이지만 실시간 촬영은 아님(주기적 갱신 위성영상).
- **3D 지구본**: 기각. CesiumJS 등으로 가능은 하지만 새로운 데이터가 생기는 게 아니라 순수 장식이라 오버엔지니어링으로 판단.
- **"살아있는" 느낌**: 6시간 이내 사건 마커에 pulse 애니메이션을 넣어, 실제 데이터 기반으로 "방금 일어난 일"을 시각적으로 구분.

## 실행

```bash
pip install -r requirements.txt
python3 scripts/fetch_data.py     # data/latest.json 생성 (키·로그인 불필요, ~30초)
python3 -m http.server 8765       # http://localhost:8765
```

소스가 실패하면 직전 성공 데이터를 유지하고 `stale: true`로 표시한다. 연결 타임아웃은 재시도.

## 배포

GitHub Pages(main 루트). `.github/workflows/update.yml`이 **매시간** 스크립트를 실행하고 `data/latest.json`을 커밋한다. 로컬에서 push하기 전에 `git pull --rebase`가 필요하다(봇 커밋과 충돌).

## 개발 프로세스

[github/spec-kit](https://github.com/github/spec-kit) 기반 Spec-Driven Development 도입. `.specify/`에 템플릿·스크립트, `.claude/skills/speckit-*`에 Claude Code 스킬이 설치되어 있다. 새 세션에서 `/speckit-specify`, `/speckit-plan`, `/speckit-tasks`, `/speckit-implement`로 이어 쓸 수 있다. 이번 배치 작업은 `specs/001-signal-audit/`에 문서화.

## 시도했지만 버린 것

- ACLED API — 무료(Open) 등급은 API 접근 불가
- 미국무부 여행경보 — Akamai 봇 차단(403)
- UKMTO 해상 속보 — Cloudflare 봇 차단
- GDELT 뉴스 검색 — 키워드 매칭이 느슨해 무관한 기사 다수
- 항공기 추적(OpenSky·adsb.lol·airplanes.live) — 사우디 상공 수신기가 거의 없거나 승인 필요
- 위키피디아 관심도 지표 — 이미 주목받아서 만든 대시보드에 주목도를 쓰는 건 순환논리라 제거
- SPA(사우디 국영통신) — Next.js 렌더링이라 정적 스크래핑 불가
- FAA DINS NOTAM(공역 폐쇄) — Akamai 403
- X/Twitter(사우디 민방위 @SaudiDCD 등) — 유료 API만
- 다른 후티 채널(Al Masirah, SABA Telegram) — 웹 미리보기 비공개
- Cloudflare Radar(사우디 인터넷 트래픽 이상탐지) — 무료지만 계정+API 토큰 필요, 자동 파이프라인에 넣기엔 등록 절차가 걸림. 가장 유망한 차기 후보로 남겨둠
- JWC(Lloyd's) 전쟁위험 해역 리스트 — 페이지 개편으로 URL 소실, 공식 PDF라 스크래핑도 불안정
- ReliefWeb API — v1 엔드포인트 폐기(410 Gone)
- Jeddah 공항 실시간 운항정보 — 공식 페이지 404, FlightRadar24는 봇 차단
- Google Translate 비공식 엔드포인트 — 요청 빈도 제한(429)이 있어 MyMemory로 대체
- 실시간 미사일 궤적/3D 지구본 — 위 "지도 고도화" 참고
- **아람코 주가·타다울 지수(시장 반응 지표)** — 처음엔 채택했으나 실전 배포 후 철회. 야후 파이낸스 비공식 API가 GitHub Actions IP를 지속적으로(일회성 아님) 429 차단. 대안으로 Stooq(프록시 오브 워크 챌린지), MarketWatch·WSJ(DataDome/Cloudflare 401), 사우디거래소 공식 사이트(403)까지 다 시도했지만 전부 봇 차단. 무료·무키로 안정적인 대안을 못 찾아 지표 자체를 뺐다 — "수집 실패"만 뜨는 지표는 없느니만 못하다고 판단.
