# Red Sea Watch · 사우디

US Pizza Index처럼, 공식 발표가 말하지 않는 것을 간접 신호로 읽는 비공식 대시보드. 사우디아라비아에 있는 한인 교민(주로 아람코 근무 가족)용. 권역 분류 없이 **도시 단위 현황표 하나**로 보여준다.

**https://junekinns.github.io/yanbu-dashboard/**

## 없앤 것과 이유

- **해상 교통(IMF PortWatch)** — 5일 지연. "지금 어떤가"에 답하지 못한다. 지도 팝업의 입항 수도 함께 뺐다.
- **위성 열 감지 타일·그래프** — 위성은 하루 두 번 지나가고 큰 화재만 잡힌다. 사건 위치와 겹쳐 볼 때만 의미가 있어 지도 레이어로만 남겼다.
- **공지 템포 그래프** — 주 단위로 바뀌는 막대는 장식. 헤드라인의 숫자 한 줄이면 충분하다.
- **서부/중부/동부 권역** — 탭 시절 유물. 사용자는 "우리 동네"를 찾지 권역을 해석하지 않는다.
- **"지금 바로 데이터 재수집 (GitHub 로그인 필요)" 링크** — 방문자에게 로그인 링크를 노출하는 것 자체가 잘못. 토큰을 페이지에 넣을 수도 없다(공개 저장소의 PAT는 GitHub이 자동 폐기).
- **위키피디아 관심도**(이전) — 이미 주목받아서 만든 대시보드에 주목도를 쓰는 건 순환논리. **아람코 주가**(이전) — 아래 "시도했지만 버린 것".

## 실험 중

- **홍해 상공 회피 (FlightRadar24 비공식 피드)** — 항공사는 위협을 인지하면 공식 경보보다 먼저 조용히 항로를 우회한다는 가설. 밥엘만데브~제다 상공(북위 12~24, 동경 35~44)의 항공편 수를 매시간 세고, 밤낮 차이가 커서 같은 UTC 시각의 과거 14일 값과만 비교한다. 공식 무료 API인 OpenSky Network를 먼저 시험했으나 사우디·홍해 상공에 지상 수신기가 거의 없어(제다·리야드 공항 반경도 실시간 0건) 기각. FR24는 위성 ADS-B까지 합쳐 같은 박스에서 40대가 잡혔고 GitHub Actions IP에서도 응답한다. 다만 지도 페이지가 내부적으로 쓰는 비공개 엔드포인트라 차단될 수 있다 — 그러면 "수집 실패만 뜨는 지표는 없느니만 못하다" 원칙대로 뺀다. 페이지 맨 아래 "실험 중" 카드.
- **사우디 공역 NOTAM (FAA NOTAM API)** — 공역 폐쇄·제한·위험구역 통보는 공식 경보보다 먼저 나오는 선행 신호. FAA API 포털(api.faa.gov → portal.apic4e.faa.gov)에서 NOTAM API에 Request Access(Production Manual Approval, 분당 50건)를 넣고 승인되면 `client_id`/`client_secret`이 나온다. 받으면 `gh secret set FAA_CLIENT_ID -R junekinns/yanbu-dashboard`, `gh secret set FAA_CLIENT_SECRET -R junekinns/yanbu-dashboard`로 저장소 비밀값에 넣는다 — 워크플로우가 환경변수로만 넘기고, 페이지·JSON·로그 어디에도 기록되지 않는다. 비밀값이 없으면 수집·화면 모두 비활성(실패 아님). 대상: OEJN 제다 · OERK 리야드 · OEDF 담맘 · OEMA 메디나 · OEJD 사우디 FIR. 응답 필드 경로는 첫 실제 응답으로 확정 예정(`specs/003-city-signals/research.md`).

## 지도 고도화: 조사 결과

Palantir AIP급 실시간 미사일 궤적·3D를 문의받아 조사함.

- **실시간 미사일 궤적/아이콘**: 불가능. 요격·발사 데이터는 각국 군 레이더 텔레메트리 영역이라 무료 공개 API가 없음(이스라엘의 Home Front Command 사이렌 API 같은 게 사우디엔 없음). 지금 지도에 찍는 사건 마커는 "보도된 사건의 대략적 위치"이지 실제 탄도 좌표가 아님 — 이 한계를 명확히 유지.
- **위성뷰**: 채택. Esri World Imagery는 무료·무키 타일이라 바탕지도 토글로 추가. 실제 위성사진이지만 실시간 촬영은 아님(주기적 갱신 위성영상).
- **3D 지구본**: 기각. CesiumJS 등으로 가능은 하지만 새로운 데이터가 생기는 게 아니라 순수 장식이라 오버엔지니어링으로 판단.
- **"살아있는" 느낌**: 6시간 이내 사건 마커에 pulse 애니메이션을 넣어, 실제 데이터 기반으로 "방금 일어난 일"을 시각적으로 구분.

## 실행

```bash
pip install -r requirements.txt
python3 scripts/fetch_data.py     # data/latest.json 생성 (키·로그인 불필요, ~1분. FIRMS 44MB CSV가 대부분)
python3 -m http.server 8765       # http://localhost:8765
```

소스가 실패하면 직전 성공 데이터를 유지하고 `stale: true` + 마지막 성공 시각(`last_ok_at`)을 남긴다(화면에는 "N시간 전 값"). 어떤 예외가 나도 그 소스만 실패 처리되고 나머지는 저장된다. 소스별 소요 시간이 한 줄씩 출력된다. 연결 타임아웃은 10초, 재시도 3회.

사건 이력을 처음 채울 때만 `EVENT_DAYS=14 python3 scripts/fetch_data.py` — Google News RSS가 100건 캡이라 국문은 ~9일, 영문은 하루치만 온다. 이력은 매시간 수집으로 쌓이는 것이 본체.

## 배포

GitHub Pages(main 루트). `.github/workflows/update.yml`이 **매시간** 스크립트를 실행하고 `data/latest.json`을 커밋한다(push 전 `git pull --rebase -X theirs`, job 타임아웃 15분). 로컬에서 push하기 전에도 `git pull --rebase`가 필요하다(봇 커밋과 충돌). 저장소 생성 당일에는 GitHub 스케줄러가 cron 슬롯을 자주 건너뛰었다 — 급하면 Actions에서 workflow_dispatch로 수동 실행.

## 개발 프로세스

[github/spec-kit](https://github.com/github/spec-kit) 기반 Spec-Driven Development. `.specify/`에 템플릿·스크립트, `.claude/skills/speckit-*`에 Claude Code 스킬. 새 세션에서 `/speckit-specify`, `/speckit-plan`, `/speckit-tasks`, `/speckit-implement`로 이어 쓴다. 이력: `specs/001-signal-audit`(탭 제거·통합 뷰·flights 실험), `specs/002-quality-audit`(정확성·견고성 결함 19건 + 배포 후 4건), `specs/003-city-signals`(도시 단위 재편·파생 신호).

## 시도했지만 버린 것

- IMF PortWatch 항만 입항·해협 통과량 — 데이터는 정상이지만 5일 지연이라 "지금"에 무용. 2026-09-17 제거
- ACLED API — 무료(Open) 등급은 API 접근 불가
- 미국무부 여행경보 — Akamai 봇 차단(403)
- UKMTO 해상 속보 — Cloudflare 봇 차단
- GDELT 뉴스 검색 — 키워드 매칭이 느슨해 무관한 기사 다수
- 항공기 추적(OpenSky·adsb.lol·airplanes.live) — 사우디 상공 수신기가 거의 없거나 승인 필요
- 위키피디아 관심도 지표 — 이미 주목받아서 만든 대시보드에 주목도를 쓰는 건 순환논리라 제거
- SPA(사우디 국영통신) — Next.js 렌더링이라 정적 스크래핑 불가
- FAA DINS NOTAM 웹 검색(공역 폐쇄) — Akamai 403. 공식 NOTAM API는 위 "실험 중"(키 대기)
- X/Twitter(사우디 민방위 @SaudiDCD 등) — 유료 API만
- 다른 후티 채널(Al Masirah, SABA Telegram) — 웹 미리보기 비공개
- Cloudflare Radar(사우디 인터넷 트래픽 이상탐지) — 무료지만 계정+API 토큰 필요. 이제 서버 측 secret은 허용하므로 다음 후보
- JWC(Lloyd's) 전쟁위험 해역 리스트 — 페이지 개편으로 URL 소실, 공식 PDF라 스크래핑도 불안정
- ReliefWeb API — v1 엔드포인트 폐기(410 Gone)
- Jeddah·Riyadh·Dammam 공항 출발 현황(결항 여부) — 공식 페이지 404, FlightRadar24 공항 보드 API는 Cloudflare 챌린지(403). 지도 피드와 달리 막혀 있음
- Google Translate 비공식 엔드포인트 — 요청 빈도 제한(429)이 있어 MyMemory로 대체
- 실시간 미사일 궤적/3D 지구본 — 위 "지도 고도화" 참고
- **아람코 주가·타다울 지수(시장 반응 지표)** — 처음엔 채택했으나 실전 배포 후 철회. 야후 파이낸스 비공식 API가 GitHub Actions IP를 지속적으로(일회성 아님) 429 차단. 대안으로 Stooq(프록시 오브 워크 챌린지), MarketWatch·WSJ(DataDome/Cloudflare 401), 사우디거래소 공식 사이트(403)까지 다 시도했지만 전부 봇 차단. 무료·무키로 안정적인 대안을 못 찾아 지표 자체를 뺐다 — "수집 실패만 뜨는 지표는 없느니만 못하다"고 판단.
