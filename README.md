# Red Sea Watch · 사우디

US Pizza Index처럼, 공식 발표가 말하지 않는 것을 간접 신호로 읽는 비공식 대시보드. 사우디아라비아에 있는 한인 교민(주로 아람코 근무 가족)용. 권역 탭으로 **서부(얀부·제다) / 중부(리야드) / 동부(담맘·다란·주베일)** 를 전환한다.

**https://junekinns.github.io/yanbu-dashboard/**

## 세 가지 지표 (권역별, 3단계 배지로 단순화)

숫자·배율 대신 위험/주의/평시(또는 정상/감소/끊김) 3단계 배지 하나로 보여준다. 상세 수치는 배지 아래 한 줄과 미니 그래프에.

| 지표 | 데이터 | 배지 |
|---|---|---|
| 위성 열 감지 | NASA FIRMS VIIRS(S-NPP) 7일 화점 CSV, 권역 bbox. 7일 중 4일 이상 같은 3km 격자에 잡히는 상시 열원(정유 플레어)은 제외 | 24시간 이상 화점 수 ÷ 평시(이력 중앙값) — 위험 / 주의 / 평시 |
| 공지 템포 | 외교부 해외안전여행 사우디 안전공지 (`ntnCd=107`), 전국 | 최근 7일 건수 ÷ 평시 중앙값 — 급증 / 증가 / 평시 |
| 해상 교통 | IMF PortWatch (AIS 집계, ArcGIS FeatureServer) — 서부 얀부 King Fahd 항, 동부 주아이마(아람코 원유 터미널), 중부는 호르무즈 해협 | 최근 7일 ÷ 지난 1년 중앙값 — 끊김 / 감소 / 정상. 유일하게 **낮을수록 위험** |

(이전에는 위키피디아 조회수로 "관심도"도 표시했으나, 애초에 사우디 정세가 이미 주목받고 있어서 만든 대시보드에 "주목도"를 지표로 쓰는 건 순환논리라 제거했다.)

## 그 외

- **외교부 경보 한 줄**: 권역 내 3단계(출국권고) 지명과 나머지 단계. 2026-09-16 기준 얀부·라스타누라·주베일·프린스술탄기지·샤이바·지잔·아브하·카미스무샤이트가 3단계, 나머지 특별여행주의보.
- **공격·요격·경보 로그**: 사우디에는 공개 사이렌 API가 없다. 민방위 경보·연합군 요격 발표가 1~2시간 안에 주요 매체에 보도되는 점을 이용해 영문·국문 Google News 결과를 허용 매체로 걸러 (현지 날짜·대상 도시·유형[경보/요격/피격/공습])로 묶는다. 부인·분석·후속 경제기사는 제외. 선택 권역은 붉은 줄.
- **후티 군 대변인 채널**: Telegram @army21ye(예멘군 대변인 야히야 사리 공식 채널)의 웹 미리보기를 읽어 사우디·사우디 지명(아랍어)을 언급한 메시지만 표시. 후티는 공격을 채널에서 먼저 예고·발표하므로 선행지표. 원문 아랍어 + 구글 번역 링크. 상대측 발표라 검증되지 않음을 명시.
- **권역 지도**: 선택 권역만, 요소 세 가지 — 도시(외교부 단계 색, 클릭하면 항만 활동), 사건(유형별 색, 매체 수 크기, 클릭하면 기사), 위성 이상 화점. 24시간/72시간/7일 범위 토글.
- **외교부 최근 공지 3건**(본문 첫 줄 요약), **언론 보도** 국내·해외 5건씩(주요 매체 허용목록, 매체당 2건).

## 실행

```bash
pip install -r requirements.txt
python3 scripts/fetch_data.py     # data/latest.json 생성 (키·로그인 불필요, ~30초)
python3 -m http.server 8765       # http://localhost:8765
```

소스가 실패하면 직전 성공 데이터를 유지하고 `stale: true`로 표시한다. 연결 타임아웃은 1회 재시도.

## 배포

GitHub Pages(main 루트). `.github/workflows/update.yml`이 6시간마다 스크립트를 실행하고 `data/latest.json`을 커밋한다. 로컬에서 push하기 전에 `git pull --rebase`가 필요하다(봇 커밋과 충돌).

## 시도했지만 버린 것

- ACLED API — 무료(Open) 등급은 API 접근 불가
- 미국무부 여행경보 — Akamai 봇 차단(403)
- UKMTO 해상 속보 — Cloudflare 봇 차단
- GDELT 뉴스 검색 — 키워드 매칭이 느슨해 무관한 기사 다수
- 항공기 추적(OpenSky·adsb.lol·airplanes.live) — 사우디 상공 수신기가 거의 없거나 승인 필요
- 위키피디아 관심도 지표 — 이미 주목받아서 만든 대시보드에 주목도를 쓰는 건 순환논리라 제거
- SPA(사우디 국영통신) — Next.js 렌더링이라 정적 스크래핑 불가
- FAA DINS NOTAM(공역 폐쇄) — Akamai 403
- X/Twitter(사우디 민방위 @SaudiDCD 등) — 유료 API만
- 다른 후티 채널(Al Masirah, SABA Telegram) — 웹 미리보기 비공개
